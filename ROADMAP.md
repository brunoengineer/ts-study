## After the course: for the rest of your career

| How often | What |
|---|---|
| **Every day** | `npm run drill`. 5-10 minutes. Cards you know well come back rarely (after 30, 60, 120 days), so it stays short. |
| **Every week** | One kata from memory. Rotate: page object, fixture, API test, auth setup, config. |
| **Every month** | Rebuild a mini framework from an empty folder in 1-2 hours (config + 1 page object + 1 fixture + 3 tests). Time yourself. You'll get faster. |
| **Every quarter** | Automate a public practice site you've never seen (ideas in the final project lesson). Read the Playwright release notes and try one new feature. |
